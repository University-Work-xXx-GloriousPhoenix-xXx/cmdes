# Схеми виконання лабораторних завдань

## Завдання 1: Моделювання експоненційного розподілу

1. **Генеруємо сировину** — створюємо масив рівномірно розподілених випадкових чисел від 0 до 1 ($\xi$).
2. **Перетворюємо дані** — перераховуємо їх в експоненційний розподіл за допомогою формули зворотної функції через заданий параметр інтенсивності $\lambda$.
3. **Рахуємо статистику** — обчислюємо емпіричні середнє і дисперсію для різних $\lambda$ і порівнюємо їх з теоретичними ($1/\lambda$ та $1/\lambda^2$).
4. **Перевіряємо гіпотезу** — оцінюємо відповідність даних закону за критерієм згоди Пірсона ($\chi^2$).
5. **Візуалізуємо** — будуємо сітку графіків (subplots 2×2), накладаючи емпіричні гістограми на теоретичні криві щільності (PDF).
6. **Висновок** — значення збігаються з теорією, а гіпотеза про експоненційний закон успішно приймається для всіх $\lambda$.

## Завдання 2: Лінійний конгруентний метод (рівномірний розподіл)

1. **Генеруємо псевдовипадкові числа** — запускаємо рекурентну формулу ЛКМ ($z_{i+1} = (a \cdot z_i) \pmod c$) з різними парами параметрів $a$ і $c$.
2. **Нормалізуємо значення** — ділимо отримані цілі числа на модуль $c$, переводячи їх у діапазон $U(0, 1)$.
3. **Рахуємо статистику** — знаходимо емпіричні середнє ($0.5$) і дисперсію ($1/12$).
4. **Перевіряємо гіпотезу** — використовуємо $\chi^2$-критерій Пірсона для перевірки рівномірності розподілу на інтервалі $(0; 1)$.
5. **Візуалізуємо** — будуємо гістограми розподілу для кожного набору параметрів ЛКМ.
6. **Висновок** — при великих і правильно підібраних параметрах числа заповнюють інтервал рівномірно (гіпотеза приймається), а при малих — генератор зациклюється і видає спотворення.

## Завдання 3: Дослідження часової затримки алгоритму сортування

1. **Запускаємо повтори сортування** — багаторазово вимірюємо реальний час виконання сортування великого масиву даних на процесорі.
2. **Знаходимо параметри розподілу** — обчислюємо середнє ($\mu$) та стандартне відхилення ($\sigma$) для підгонки під нормальний закон.
3. **Перевіряємо на нормальність** — тестуємо вибірку за допомогою тесту Шапіро-Вілка.
4. **Створюємо симуляцію** — будуємо штучний імітаційний генератор, використовуючи знайдені параметри нормального розподілу.
5. **Порівнюємо дані** — перевіряємо подібність реальних замерів і симуляції за допомогою KS-тесту (Колмогорова-Смірнова).
6. **Висновок** — тест Шапіро фіксує мікровідхилення через фонові шуми ОС, проте KS-тест підтверджує, що створена імітаційна модель адекватно відтворює загальний характер затримок.
